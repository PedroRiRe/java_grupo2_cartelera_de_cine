### Descripción del Proyecto
Esta aplicación está diseñada con entidades, controladores, enumeraciones, excepciones, repositorios, servicios, implementaciones, seguridad, HTML y CSS para que los usuarios puedan acceder a todas las funcionalidades de la plataforma. Si el usuario se encuentra registrado, la aplicación le permite realizar funciones adicionales y exclusivas.

### Entidades Principales
* Dirección
* Cine
* Película
* Género
* Clasificación
* Sala
* Usuario
